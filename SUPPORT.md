# Support

## Documentation

- [Playbook docs](https://github.com/pragmatic-engineer/playbook/blob/main/docs/index.md)
- [Quick start](https://github.com/pragmatic-engineer/playbook#quick-start-1-command)
- In a Claude Code session, run `/playbook:doctor` to check your setup.

## Questions and bugs

- Search the open and closed issues of the relevant repo first.
- Open an issue with the bug report or feature request form in the repo the problem belongs to.
- Include the version, your operating system and the exact command or error output.

## Security

Do not open a public issue for a vulnerability. Follow the [security policy](https://github.com/pragmatic-engineer/.github/blob/main/SECURITY.md).

## Response times

These are open source projects maintained on a best effort basis. There is no guaranteed response time.
